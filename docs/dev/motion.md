# 动效设计文档

这份文档说明本项目的动效用在哪、怎么选、参数是多少、哪些坑踩过，以及做新功能时怎么把动效算进去。

**做功能时必须考虑动效**：一个改动带出的「出现 / 消失 / 切换 / 刷新 / 加载」都应该有明确的动效决定——要么按本文加，要么明确不加（写注释说明），不要默认没有。参数集中在 `internal/app/motion.go` 顶部，改参数不要散落到视图里。

---

## 1. 三条原则

1. **动的是状态变化，不是「页面加载」**
   一次变化只用一个动作。两个动作叠在一起（页面整体上移 + 行再上移）就会显刻意——这一版就是从这里改过来的。

2. **一是快，二是连**
   常用时长 140–320ms，超过 400ms 只有歌词 genie 这种「必须看得清过程」的才用。
   相邻元素错开要**小于一帧（≤ 8ms）**：15ms / 25ms 的间隔等于一帧一步，看起来像报数；8ms 时一帧里有两三个元素在动，才是一条连续的波。

3. **不要遮住内容自己的变化**
   歌曲列表的行是虚拟列表分帧填进来的（`ui.List` 逐帧量行高）。整页淡入会把这几十毫秒盖掉，看起来就是「一起出现」。想让内容有层次，就给它自己的动效，而不是用一层淡入去糊。

补充：动效要能被打断而不跳。连续量（队列宽度、歌词进度、页签滑块）用 `AnimateTo` + 弹簧，新的目标从当前值出发；一次性姿势用 `AnimatePose`。

## 2. 工具怎么选（MyGo v0.7.1）

| 手段 | 用在哪 | 关键点 |
|---|---|---|
| `ui.ElementTransition` + `.Transition(...)` | 元素身份跨帧稳定、但状态会变：**页面** | 整帧布局后统一采样，一次事件把视图重建两遍也不会丢；`Exit` 会留一份「拷贝」继续画（ghost） |
| `ui.Pose` + `Element.AnimatePose(pose, anim)` | 自己控制的一次性出现/消失：`appear`、`presence`、`tabMotion`、`refreshMotion`、歌词、播放栏 | 一帧只保留最后一次姿势；用 `c.AnimationFrame()` 要到下一帧 |
| `appear(c, el, &in, out, anim)` / `presence` | 面板、歌词、队列、评论的进退 | `in` 是一个「已经出现过」的标记，不是元素本身 |
| `Element.AnimateTo("名字", 值, anim)` | 连续量：队列房间宽度、歌词 genie 进度、页签滑块、歌词行字号 | 每帧读值，可以被新目标随时打断 |
| `c.After(d)` / `c.AnimationFrame()` | 需要按时间/下一帧继续时 | 只在真的还需要一帧时调，否则 `TestFrameBudget` 会红 |
| `tintFade`（`palette.go`） | 页面顶部取色随封面变化 | 600ms ease-out，颜色比位移慢 |
| `ui.Animation{Spring: ...}` | 一切位移/透明度 | 零值 `Animation{}` 等于 `ui.Smooth`：spring **500ms**、无回弹，偏慢，一般都显式写时长；`ui.Snappy`（Bounce .15）/ `ui.Bouncy`（Bounce .3）同样是 500ms |

### 三条硬约定（踩过的）

1. **`ui.Motion` 的 `Opacity` 零值是 0，也就是「透明」**。只想位移、不想淡入，必须写 `Opacity: 1`。
2. **页面不要给 `Exit`**。上一页的拷贝会和新页同时画，两页的文字和卡片对不齐，就是重影。
3. **不要用 `AnimatePose` 做「换页面」这类跨事件的身份变化**：点击改页面发生在某一帧中间，一帧里视图会重建一遍，而一帧只保留最后一次姿势，入场姿势会被同帧那次重建吃掉（这就是「页面切换没有动画」的历史原因）。

## 3. 参数总表

参数都在 `internal/app/motion.go`（除注明）。

| 场景 | 变化 | 时长 / 曲线 |
|---|---|---|
| 页面进场 | 上移 10px，**不淡入** | spring 210ms |
| 歌曲列表行 | 上移 4px，透明度 20% → 100%，行间错开 8ms（最多 12 行） | spring 170ms，Bounce 0.1 |
| 歌曲列表少一行（取消喜欢） | 它下面的行从原位置滑上来，48px（= `songRowHeight`） | 同 `rowsSpring`，一起走、不逐个错开 |
| 队列房间宽度 | 宽度跟随 | `sideSpring` spring 300ms |
| 队列/评论面板本体 | 从右滑入（`panelIn`）/滑出淡出（`panelOut`） | 跟随房间，`appear` 300ms |
| 页签滑块 | 位置跨越 | `pillSpring` spring 260ms |
| 搜索框下拉菜单 | −6px + 缩放 0.96 + 淡入，左上角为原点 | `menuMotion` spring 160ms |
| 弹出菜单（音质/播放模式/账号） | 从锚点上浮 6px + 淡入 | `popupMotion` 140ms |
| 播放栏切歌 | 横向滑 96px + 交叉淡出 | `songSpring` spring 300ms，Bounce 0.1 |
| 歌词面板收放 | genie 弯折收缩到封面 | `lyricsSpring` spring 560ms |
| 歌词换行 | 字号 320ms / 颜色 240ms / 悬停底色 150ms / 列表滑动 320ms | 全部 spring |
| 歌手页页签 | 行上移 14px + 淡入，行间 8ms（最多 8 行） | `tabSpring` spring 300ms |
| 首页「换一批」 | 卡片上移 12px + 淡入，错开 8ms | `cardSpring` spring 300ms |
| 页签内容（音乐馆/搜索/小宇宙/播客/设置） | **只淡入、不位移**（`paneTransition`） | 160ms |
| 队列行增删 | 行收放（`Collapse`）+ 下面的行滑上来 | `queueRow` 200ms |
| 对话框（登录） | 遮罩淡入 / 面板上移 8px + 淡入 | `dialogFade` 160ms / `dialogSpring` 200ms，Bounce 0.1 |
| 来源卡片悬停 | 上浮 5px + 放大 1.025 | `hoverSpring` 200ms，Bounce .15 |
| 骨架屏呼吸 | 透明度 0.45–1 | `pulseLoop` 1400ms，ease-in-out |
| 播放中的均衡器 | 三根柱子各自起落 | `eqBeat` 500ms + k × `eqStep` 170ms |
| 页面顶部取色 | 颜色插值 | 600ms ease-out（`tintDuration`） |
| 换一批转圈 | 转一圈 | `refreshSpin` 1s |

## 4. 各区域现状

- **页面切换**（`view.go`）：页面容器 `.Transition(pageTransition)`；上一页直接换掉，新页原地淡入 + 上移 10px。切换来自侧边栏、卡片、顶栏、键盘都一样。
- **歌曲列表**（`view_pages.go` 的 `songTable` + `motion.go` 的 `rowsMotion`）：首屏的行按顺序逐行进场；`show(key)` 以页面 key 或搜索词为身份，换页/换查询才重新打散，滚动回来的行、正在看时新增的行都不重放；起手 250ms 之后才进视野的行直接显示。
- **歌曲列表少一行**：`loadList` 重新加载后若少了一首（取消喜欢就是这样），`rowGone` 找出少的是第几行，`rowsMotion.shifted(i, songRowHeight)` 让该行以下的行先摆回原来的位置再滑上来——`ui.List` 自己排行、不会动，所以只能靠姿势。行高常量 `songRowHeight` 必须和行的内边距 + 封面高度一致。
- **歌手页页签**（`tabMotion`）：切页签、换排序时逐行。
- **首页「换一批」**（`refreshMotion`）：卡片依次，图标同时转。
- **歌词**：genie 收放、每行字号/字重/颜色、换行滑动（`lyricScroll` 先量后滑，避免跳）。
- **队列 / 评论**：`presence` + 房间宽度，跨页面时改用「面板自己滑动」。
- **菜单与弹窗**：`menuOut` / `popupRise`。
- **播放栏**：切歌滑动，封面取色（`barTint`）。
- **页签内容**（`pane`）：音乐馆两页、搜索页签、小宇宙三页签、播客搜索结果、设置分区——换页签时只淡入，因为上面的页签不动、页面已经在那里，位移会让指针下的目标跟着走。
- **队列**（`view_player.go`）：队列用 `ui.Scroll` + 键控列，**不是 `ui.List`**——`ui.List` 的行位置由列表自己排，行的 Transition 拿不到位置变化，删歌时只会硬跳；换成列之后行按「歌曲 + 同名出现次序」保住身份，删掉的一行收起、下面的行滑上来（实测标签 327→316→300→289→283→280）。
- **卡片网格**（`refreshMotion.show(key)`）：歌单广场按分类、首页 feed 按分组标题、新歌首发按页面；首批卡片依次进场，翻页追加的不重放。
- **设置**：容量条按 `sideSpring` 长到实际占用。
- **登录对话框**：`dialogFade` / `dialogSpring`，只在打开时；关闭交给 Escape 或点外面，直接消失。

## 5. 反模式

1. 用整页淡入「做动画」→ 盖住列表自然的填充，看起来一起出现。
2. 页面加 `Exit` → 旧页拷贝叠在新页上，重影。
3. 用 `AnimatePose` 做换页面 → 同帧重建吃掉姿势，等于没动画。
4. 行间错开 ≥ 一帧（15/25ms）→ 像报数；≤ 8ms 才是波。
5. 起手全透明 + 大位移（12px）→ 刻意；从 20% 亮度、4px 起步更像自然浮现。
6. 位移和淡入都从 0 起步、还都是「从静止慢慢加速」的零超调弹簧 → 起手一大段看不见，然后突然动。小位移加一点 Bounce（0.1）收尾更自然。
7. 在 `view` 构建期发请求、改队列（见 `AGENTS.md` §2.4）；动效状态在构建期读写是允许的，但要幂等。

## 6. 新功能加动效的检查清单

- [ ] 这次是哪种变化：出现 / 消失 / 切换 / 刷新 / 加载 / 连续拖动？
- [ ] 只用一个动作，还是两个叠在一起？（叠了就减掉一个）
- [ ] 时长 ≤ 320ms？相邻元素错开 ≤ 8ms？
- [ ] 会不会遮住内容自己的变化（列表填充、图片陆续到达）？
- [ ] 身份跨帧稳定吗？稳则用 `ElementTransition`，一次性姿势用 `AnimatePose`。
- [ ] 只想位移/只想淡入时，`Opacity` 和 `Position` 写对了吗？
- [ ] 换的是「页签内容」而不是「页面」？页签内容只淡入，别位移（指针下的目标不能跟着走）。
- [ ] 只在绘制帧里跑吗？静止页面不能持续重建（`TestFrameBudget`）。
- [ ] 减少动态（Reduce Motion）下怎么办？（`Motion` 只有淡入时 `fades()` 为真，才会保留为原地淡入）
- [ ] 参数写进 `motion.go` 了，还是散在视图里？
- [ ] 有测试守着吗？

## 8. v1.0.8 这次改了什么（含按本文做的规则 review）

**问题**：切换左侧 tab 时页面像硬切。

**原因**：页面入场本来用 `appear` + `ui.Pose`，但点击改页面发生在某一帧中间，视图会在同一帧重建一遍，而一帧只保留最后一次姿势，入场姿势被同帧那次重建覆盖成「原地显示」——等于没有动画。

**改动**：

1. 页面进场改为 `ui.ElementTransition`（`motion.go` 的 `pageTransition`）：`Enter` 上移 10px、`Opacity: 1`（不淡入），spring 210ms；**不加 `Exit`**，上一页直接换掉。
2. 歌曲列表新增 `rowsMotion`（`songTable` 传入 `&l.rows`／`&a.search.rows`）：行从 20% 亮度、上移 4px 浮现，行间 8ms，spring 170ms（Bounce 0.1），最多错开 12 行；起手 250ms 后才进视野的行直接显示。
3. 删掉只为页面姿势服务的 `pageIn` / `pageShown`，页面 key 直接取 `a.current().key()`。
4. 补测试：`TestPageSwitchAnimates`、`TestRowsComeInOneByOne`；`TestHistoryKeyAnimates` 的阈值随「淡入 → 上移」调整。

**2026-10-29 的规则 review 与修复**：按本文把已有功能过了一遍，改掉的是——页签内容硬切（现在 `paneTransition`）、页签/换一批的错开 30/25ms（改 8ms）、`songSpring`/`tabSpring`/`cardSpring` 380ms（改 300ms）、来源卡片 hover 的 `ui.Snappy`（500ms 内联 → `hoverSpring` 200ms）、搜索下拉整面板淡入（入场改只位移）、播客单集列表没有逐行入场、队列增删硬跳、卡片网格首屏、设置分区与容量条、登录对话框。

## 9. 明确不加动效的地方

写在这里，就不必在代码里找「为什么这里没有动画」：

- **右键菜单**：`ui.Menu` 是系统原生菜单（`platform.Menu`），动画归操作系统，做不了也不该做。
- **队列拖拽排序**：功能本身不存在；将来加时按「行收起/插入」的思路做。
- **播放模式、音质切换的结果**：菜单本身有 `popupUp`，选完图标硬切可以接受，不再加。
- **「我喜欢」红心**：乐观更新、颜色与图标一起切；要加就是 150ms 颜色，不加也可接受（现状：不加）。
- **退出登录**：侧边栏整块直接换；身份变化不做动效。
- **窗口缩放**：`ElementTransition` 在缩放时整段不动画（库的行为），保持一致。

## 10. 中间试过又回滚的方案（免得再走一遍）

- 页面留 `Exit` 做交叉淡出 → 两页同时画，重影，否掉。
- 页面纯淡入、不位移 + 行纯淡入（`rowsOut{Fade: 0.9}`）→ 没有任何位移，反而显得像没做完，否掉。
- 行间 25ms、单行 320ms → 太慢，像报数。
